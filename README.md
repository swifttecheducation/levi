## 🌟 7 Đột Phá Công Nghệ Cốt Lõi

1. **Hỗ Trợ MỌI Trợ Lý AI (Omni-AI Architecture):**
   - Không bị bó hẹp vào một công cụ. Hỗ trợ đầy đủ bộ điều khiển cho **Gemini / Antigravity** ([`GEMINI.md`](GEMINI.md)), **Claude Code** ([`CLAUDE.md`](CLAUDE.md)), **ChatGPT / Custom GPTs** ([`chatgpt-system-prompt.md`](chatgpt-system-prompt.md)) và **Cursor** ([`.cursorrules`](.cursorrules)).
2. **Cơ Chế Làn Kép Song Song (Dual-Lane Output):**
   - **Làn Nhanh (Fast-Lane):** Tự động sinh file dự án **CapCut Desktop** đa track rời lớp (`draft_content.json`) để mở lên chỉnh sửa nhanh ngay trên màn hình chính.
   - **Làn Điện Ảnh (Pro-Lane):** Tự động sinh Timeline **Adobe Premiere Pro XML** (`.xml`) kết hợp kịch bản **After Effects ExtendScript** (`.jsx`) tích hợp biểu thức nảy đàn hồi lò xo (*Inertial Bounce Expression*) và rung lắc tự nhiên, hỗ trợ render ngầm GPU bằng `aerender.exe`.
3. **Khóa Cằm AI Chin-Lock 3D & Né Mặt (OpenCV YuNet):**
   - Sử dụng mô hình nơ-ron YuNet (`assets/models/face_detection_yunet_2023mar.onnx`) quét cằm và góc nghiêng đầu từng frame, tự động neo phụ đề và thẻ hook bên dưới xương quai xanh (Collar Line), tuyệt đối không bao giờ che mắt hoặc miệng người nói.
4. **Chuẩn Âm Thanh Phát Sóng (EBU R128 -14 LUFS):**
   - Tự động cân bằng âm lượng giọng nói chuẩn đài truyền hình, kiểm soát True Peak dưới -1.5 dBTP và tự động giảm âm lượng nhạc nền ngầm (Audio Ducking -18dB) khi có tiếng nói.
5. **Đồ Họa Code Remotion 60fps & Kênh Alpha Trong Suốt:**
   - Xuất các đoạn motion graphics phức tạp (Code viewer gõ chữ, bảng thống kê nhảy số, terminal) thành video trong suốt kênh Alpha (ProRes 4444 / WebM VP9) để phủ trực tiếp vào Premiere hoặc CapCut.
6. **Bảng Phân Cảnh Storyboard Beat Sheet (Duyệt Trong 10 Giây):**
   - Xuất ảnh lưới contact sheet (`outbox/<tên>_beat_sheet.jpg`) chứa 6-12 khung hình then chốt có đánh số phân cảnh để người sáng tạo duyệt chữ, bố cục và màu sắc trước khi render nặng.
7. **Trọn Bộ Đa Kênh Chuẩn Brand Kit (Quay 1 Lần — Đăng Mọi Nơi):**
   - Tự động tạo bộ bài đăng vuốt ngang **Instagram Carousel (1080x1350)** và chuỗi tin ngắn **Story Kit (9:16)** chừa sẵn vị trí dán Sticker tương tác (Poll, AMA, Link), kèm 3 biến thể video thử nghiệm **Trial Reels** cho thuật toán A/B Testing.

## ⚡ Bắt Đầu Nhanh (3 Phút)

### 1. Cài đặt thư viện
```bash
pip install -r requirements.txt
```

### 2. Kiểm tra trạng thái hệ thống
```bash
python studio.py status
```

### 3. Dựng video tự động 1-chạm
Thả video thô mới quay vào thư mục `inbox/` và chạy:
```bash
python studio.py autopilot
```

## 🛠️ Danh Sách Khẩu Lệnh Tiếng Việt

| Khẩu Lệnh Bạn Nói | Lệnh CLI Tương Ứng | Tác Vụ Của Hệ Thống |
| :--- | :--- | :--- |
| **"cài đặt cho mình"** / **"onboarding"** | `python studio.py onboard` | Chạy quy trình hướng dẫn 4 bước thiết lập ban đầu và Brand Kit |
| **"thiết lập thương hiệu"** / **"brand"** | `python studio.py brand` | Phỏng vấn chuyên sâu 7 trụ cột ADN thương hiệu và sửa lỗi phiên âm |
| **"chế độ đạo diễn"** / **"director"** | `python studio.py director` | Luồng khoa học hỏi ý kiến bạn từng bước (Màu sắc, J-Cut, SFX, Export) |
| **"dựng video"** / **"autopilot"** | `python studio.py autopilot` | Dựng tự động toàn diện 1-chạm từ A-Z cho video trong `inbox/` |
| **"xuất premiere"** | `python studio.py premiere -v <video>` | Xuất Timeline FCPXML mở trực tiếp trong Adobe Premiere Pro |
| **"xuất after effects"** | `python studio.py ae -t "<câu_hook>"` | Xuất kịch bản After Effects ExtendScript JSX nảy lò xo |
| **"cho xem beat sheet"** | `python studio.py beat-sheet -v <video>` | Xuất ảnh Storyboard đánh số phân cảnh để duyệt trước |
| **"tạo carousel"** | `python studio.py carousel -H "<tiêu_đề>"` | Tạo bộ bài đăng vuốt ngang Instagram Carousel (1080x1350) |
| **"kiểm tra hệ thống"** / **"status"** | `python studio.py status` | Báo cáo cấu hình Brand Kit, font chữ và video đang chờ |
