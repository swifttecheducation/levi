## 💻 CÁCH KHỞI CHẠY ONBOARDING

Tại thư mục gốc của dự án, bạn chỉ cần gõ:
```bash
python studio.py onboard
# Hoặc: python studio.py setup
```

Hoặc trong cửa sổ chat với bất kỳ Trợ lý AI nào (Gemini, Claude, ChatGPT, Cursor), bạn chỉ cần gõ:
> *"cài đặt cho mình"* hoặc *"bắt đầu"* hoặc *"onboarding"*
